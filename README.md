## Overview

This version of the WebStudio landing page expands the interface with a modal dialog, form elements, overlays, and more advanced interaction styling.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Forms
- CSS Transitions
- Git & GitHub

## Implemented Features

- modal window with backdrop;
- styled form controls;
- labels and input fields;
- close button and interactive states;
- transition effects;
- overlay-based interface elements;
- expanded footer and contact form styling.

## Learning Outcomes

- building and styling forms;
- modal and backdrop structure;
- form focus states;
- overlay positioning;
- transitions and interactive UI elements;
- combining semantic markup with more complex visual components.
